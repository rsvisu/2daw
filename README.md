## TFG: Nexus

Asistente con IA para la web del CPIFP Los Enlaces. Los visitantes le preguntan sus dudas desde un chat integrado en la web del centro, y responde usando RAG sobre la documentación del centro (ciclos, información general…). Desde un panel de administración se pueden revisar las conversaciones, gestionar los documentos de la base de conocimiento y configurar el asistente.

| Descripción | Repositorio |
|---|---|
| API | [PI_NexusBackend](https://github.com/rsvisu/PI_NexusBackend) |
| Widget de chat | [PI_NexusWidget](https://github.com/rsvisu/PI_NexusWidget) |
| Panel de administración | [PI_NexusDashboard](https://github.com/rsvisu/PI_NexusDashboard) |
