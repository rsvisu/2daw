# TFG

## Nexus

Asistente con IA para la web del CPIFP Los Enlaces. Responde las dudas de los visitantes usando RAG sobre la documentación del centro y se gestiona desde un panel de administración.

- API REST en Express con LangChain, OpenAI y Supabase: [PI_NexusBackend](https://github.com/rsvisu/PI_NexusBackend)
- Widget de chat en Vue que se incrusta en la web con una sola etiqueta `<script>`: [PI_NexusWidget](https://github.com/rsvisu/PI_NexusWidget)
- Panel de administración en Vue para las conversaciones, la base de conocimiento y la configuración: [PI_NexusDashboard](https://github.com/rsvisu/PI_NexusDashboard)
